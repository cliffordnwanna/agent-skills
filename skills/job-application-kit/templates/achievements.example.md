# Achievements (private)

Copy to `private/achievements.md`. Add only things that are **true and cleared for use in applications**. The skill uses these as the source for CV bullets and interview answers, and will not invent anything beyond them. Keep it private; do not commit it.

For work at an employer, include a figure only if you are allowed to share it publicly. If unsure, describe the capability instead of the number.

```
- project_or_role: "<name>"
  what_i_did: "<one sentence, plain>"
  tools: ["<tool>", "<tool>"]
  result: "<real outcome, with a figure only if true and shareable>"
  link: "<public link if any>"
  cleared_to_share: yes | capability-only | no
```

Repeat for each project or role. Five to ten entries is plenty to start.
