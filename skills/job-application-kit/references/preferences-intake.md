# Preferences intake

Run this once, when `private/preferences.md` is missing, and again whenever the user says their goals changed. Ask the questions **one at a time**, with the offered options, and keep it short. Save the answers to `private/preferences.md` using `templates/preferences.example.md`.

Before asking, read the user's portfolio and use it to **suggest answers**, so most questions are a confirm or a tweak.

## The six questions

**1. Target roles and level.**
Read the portfolio and propose two or three role titles and a seniority level from the evidence (projects, years, scope). Ask the user to confirm or edit. State clearly that this is your reading of the portfolio, not a fact.

**2. Where do you want to work?** Pick one or both:
- **Remote** (work from where I live)
- **Relocation with visa sponsorship** (on-site or hybrid abroad)

Only if relocation is chosen, ask: which countries, or "open to any"? If sponsorship matters a lot, say so; the skill will then rank sponsorship-offering roles higher and verify the claim.

**3. Type of employment.** Pick one:
- Full-time employee
- Contract or freelance
- Either

(Default rule, no question: equity-only pay never counts as pay. Equity is upside on top of guaranteed compensation. The user can change this in the file.)

**4. Pay.** Ask in one go:
- Currency and unit (for example USD per hour, USD per month)
- **Walk-away floor**: below this, a job is flagged in the report. It is never removed or blocked. A low floor is fine if the user wants to see everything.
- **Target**: what they actually want. Jobs between floor and target are marked "negotiate".
- How they can receive payment (bank transfer, Wise, Payoneer, other) and any route they refuse.

Explain that unstated pay is never a rejection.

**5. Location and time.** Ask:
- The country they will work from.
- The widest timezone overlap they accept (for example "up to 6 hours from my time").
- Country-restricted jobs are flagged, never dropped. When the restriction is unclear, add the question for the recruiter to the action plan.

**6. Practical.** Ask in one go:
- Notice period or start date.
- Applications per week they can manage.
- Anything that is an automatic no (optional, free text). The skill adds the standard scam signs itself.

## Defaults, not questions

Change these only if the user asks:
- CV shows: name, email, city and country, portfolio link, LinkedIn. It hides phone and street address.
- Cover letter voice: ask for a short sample of the user's own writing the first time a letter is written, not now.
- Equity-only pay does not count (see question 3).

## Finish

Show the saved summary in five lines and ask the user to confirm. Remind them the file is private and must not be committed or shared.
