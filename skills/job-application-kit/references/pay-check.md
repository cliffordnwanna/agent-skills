# Pay and value check

Compare the listing with the user's pay settings in `private/preferences.md`. **Flag, never silently filter.**

## Normalise first

Convert both sides to the user's unit. For a full-time role:
- monthly = hourly x 173 (that is 40 hours x 52 weeks / 12)
- annual = monthly x 12
For contract or part-time roles use the stated hours. For a salaried role, convert to an approximate hourly rate using the stated weekly hours; if none are stated, assume 40 hours a week and say so. State every conversion you make, and note that an approximate hourly figure for a salaried role is only a comparison aid.

## Decide

| Situation | Result |
|---|---|
| At or above the target | **Strong**: continue |
| Between floor and target | **Acceptable, negotiate**: continue and prepare a counter |
| Below the floor | **Flag** in the report with the figures and a note on whether it is negotiable. Continue the work. |
| Pay not stated | **Ask**: never reject; add "ask the recruiter for the pay range" to the action plan |
| Equity-only or commission-only | Does not count as pay (default rule): flag |

## Check the market (with sources)

Look up current pay ranges for this role, level, and location type from reputable, current sources, and cite them. If the data is thin or old, say so. Never present a market number you could not source. Compare the listing with the range and say whether it looks low, fair or unusually high (unusually high can be a red flag, see `legitimacy-checklist.md`).

## Value beyond the headline

Note, where stated: guaranteed vs variable pay, contractor vs employee (benefits, paid leave, equipment), payment currency and how the user would receive it (their accepted routes), contract length and notice, and any restriction on other work. Equity is upside only.

This is information, not tax or legal advice. Suggest the user confirm tax and contract terms with a qualified adviser when an offer arrives.

## Never reveal

Do not state the user's floor or target in anything meant for the employer. When asked for a salary expectation, use the answer-bank rule.
